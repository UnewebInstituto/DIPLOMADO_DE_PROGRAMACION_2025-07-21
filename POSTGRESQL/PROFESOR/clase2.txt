El comando más común y robusto para hacer una copia de seguridad es **`pg_dump`**. Este comando exporta el contenido de una base de datos de PostgreSQL en un formato que luego puede ser restaurado.

### Comando Principal

```bash
pg_dump -h <host> -U <usuario> -d <nombre_base_datos> -W -Fp > <ruta_archivo>.sql
```

### Explicación de los Parámetros

  * **`-h <host>`**: Especifica el servidor donde se encuentra la base de datos (por ejemplo, `localhost` o una IP).
  * **`-U <usuario>`**: Define el usuario de PostgreSQL que tiene los permisos para acceder a la base de datos.
  * **`-d <nombre_base_datos>`**: Indica el nombre exacto de la base de datos que quieres respaldar.
  * **`-W`**: Es opcional, pero muy útil. Hace que el comando te pida la contraseña del usuario de forma segura en lugar de tenerla expuesta en la línea de comandos.
  * **`-Fp`**: Establece el formato de salida como "plain text" (texto plano), que genera un script SQL estándar y legible.
  * **`> <ruta_archivo>.sql`**: Redirige la salida del comando a un archivo con la extensión `.sql`, creando tu archivo de backup.

-----

### Ejemplo Práctico

Imagina que tienes una base de datos llamada `mi_tienda_online` en tu máquina local, a la que accedes con el usuario `postgres`. Quieres guardar el backup en un archivo llamado `backup_diario.sql` en tu escritorio.

```bash
# Navega hasta el directorio donde quieres guardar el backup
cd /home/tu_usuario/Escritorio

# Ejecuta el comando de pg_dump
pg_dump -h localhost -U postgres -d mi_tienda_online -W -Fp > backup_diario.sql
```

Después de ejecutar este comando, el sistema te pedirá la contraseña del usuario `postgres`. Una vez que la ingreses, se creará el archivo `backup_diario.sql` con el script de tu base de datos.

### ¿Cómo Restaurar el Backup?

Para restaurar este backup, usarías el comando **`psql`**:

```bash
psql -h <host> -U <usuario> -d <nombre_base_datos_nueva> -W -f <ruta_archivo>.sql
```

Simplemente reemplaza los parámetros con la información de tu nueva base de datos y el archivo de backup.

Asumo mi rol de experto en PostgreSQL. Aquí te presento el comando principal para realizar la **recuperación (restauración)** de una base de datos a partir de un archivo de backup, junto con un ejemplo práctico y los parámetros más importantes.

El comando más común y directo para restaurar un backup creado con `pg_dump` es **`psql`**. Este comando se usa para ejecutar scripts SQL, y el archivo de backup es precisamente un script con todas las sentencias necesarias para recrear la base de datos.

### Comando Principal

```bash
psql -h <host> -U <usuario> -d <nombre_base_datos_destino> -W -f <ruta_archivo>.sql
```

### Explicación de los Parámetros

  * **`-h <host>`**: Especifica el servidor de PostgreSQL donde se restaurará la base de datos.
  * **`-U <usuario>`**: Define el usuario de PostgreSQL con los permisos necesarios para crear objetos en la base de datos.
  * **`-d <nombre_base_datos_destino>`**: Indica la base de datos a la que se cargarán los datos. **Importante:** La base de datos debe existir antes de ejecutar este comando. Si no existe, puedes crearla con el comando `createdb`:
    `createdb -h <host> -U <usuario> <nombre_base_datos_destino>`
  * **`-W`**: Como en `pg_dump`, hace que el comando te pida la contraseña del usuario de forma segura.
  * **`-f <ruta_archivo>.sql`**: Especifica la ruta y el nombre del archivo de backup que se utilizará para la restauración. La opción `-f` significa "file".

-----

### Ejemplo Práctico

Imagina que tienes un archivo de backup llamado `backup_diario.sql` en tu escritorio y quieres restaurarlo en una base de datos nueva llamada `restauracion_tienda` en tu máquina local.

Primero, si la base de datos de destino no existe, debes crearla:

```bash
createdb -h localhost -U postgres restauracion_tienda
```

Una vez que la base de datos `restauracion_tienda` ha sido creada, puedes proceder con la restauración:

```bash
# Navega hasta el directorio donde se encuentra tu archivo de backup
cd /home/tu_usuario/Escritorio

# Ejecuta el comando de psql para restaurar
psql -h localhost -U postgres -d restauracion_tienda -W -f backup_diario.sql
```

Después de ejecutar este comando, el sistema te pedirá la contraseña del usuario `postgres`. Una vez que la ingreses, el contenido de `backup_diario.sql` se ejecutará, recreando las tablas y datos en la base de datos `restauracion_tienda`.

Si tu backup fue realizado en un formato diferente al "plain text" (como el formato personalizado `.dump`), la herramienta a utilizar es **`pg_restore`**. Este comando es más flexible y permite restaurar solo un subconjunto de datos si lo necesitas.
